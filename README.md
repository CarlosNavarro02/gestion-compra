# Gestión de la compra 🛒

Aplicación sencilla para gestionar la lista de la compra.

## Funcionalidades

- Añadir productos con cantidad y categoría
- Marcar productos como comprados
- Filtrar por pendientes / comprados
- Eliminar productos o limpiar los comprados
- Los datos se guardan en el navegador (`localStorage`)

## Uso

Abre `index.html` en el navegador. No necesita instalación ni servidor.

También se puede publicar gratis con **GitHub Pages**:
`Settings → Pages → Branch: main / (root)`.

## Estructura

```
index.html   Interfaz
styles.css   Estilos
app.js       Lógica de la lista
```
